# RailConnect AI

RailConnect AI is a smart railway assistant designed to enhance the travel experience of passengers by integrating multiple railway services into a single, unified platform.

## Overview

Train journeys in India often lack real-time service accessibility, efficient communication, and a centralized system for managing passenger needs. RailConnect AI aims to solve this by offering a digital solution that connects passengers, attendants, vendors, and railway operations.

This project focuses on building a seamless ecosystem where passengers can access essential services directly from their mobile devices without confusion or delay.

## Problem Statement

Passengers traveling by train face multiple challenges:

- Difficulty in requesting cleaning and assistance
- No centralized food ordering system across coaches
- Lack of real-time service communication with attendants
- Poor visibility of train status and delays
- Fragmented apps for booking, tracking, and services

These issues result in inconvenience, inefficiency, and a poor travel experience.

## Solution

RailConnect AI provides an integrated platform that offers:

- Real-time train tracking and updates
- Smart service request system for cleaning and assistance
- Food ordering system with seat-based delivery
- AC temperature adjustment requests
- Notification system for delays and announcements
- Role-based access for passengers, attendants, and vendors

The application uses a simplified interface with intelligent backend logic to simulate real-world railway operations.

## Key Features

### Passenger Features
- PNR-based identification system
- Cleaning and service request
- Food ordering with Cash on Delivery
- AC temperature adjustment request
- Live train tracking and ETA
